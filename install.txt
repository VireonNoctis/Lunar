LUNAR BOT — INSTALLATION GUIDE

This installation guide matches the current Lunar source tree.

---

1. PYTHON VERSION

---

Required:

Python 3.10+

Recommended:

Python 3.11 or newer

---

2. REQUIRED PYTHON PACKAGES

---

Install:

discord.py
aiohttp
Flask
scylla-driver
akinator
python-dotenv
Pillow

Dashboard dependencies:

fastapi
pydantic
aioredis
SQLAlchemy

Optional dashboard server:

uvicorn

---

3. ONE-COMMAND INSTALL

---

Main bot + dashboard:

python -m pip install -U discord.py aiohttp Flask scylla-driver akinator python-dotenv Pillow fastapi pydantic aioredis SQLAlchemy uvicorn

---

4. VIRTUAL ENVIRONMENT

---

Linux/macOS:

python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -U discord.py aiohttp Flask scylla-driver akinator python-dotenv Pillow fastapi pydantic aioredis SQLAlchemy uvicorn

Windows PowerShell:

py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -U discord.py aiohttp Flask scylla-driver akinator python-dotenv Pillow fastapi pydantic aioredis SQLAlchemy uvicorn

Windows CMD:

py -3 -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
python -m pip install -U discord.py aiohttp Flask scylla-driver akinator python-dotenv Pillow fastapi pydantic aioredis SQLAlchemy uvicorn

---

5. WHAT EACH PACKAGE IS FOR

---

discord.py
Discord bot framework, commands, slash commands, views,
buttons, modals, events, cogs and tasks.

aiohttp
Asynchronous HTTP requests used by Lunar integrations
and external APIs.

Flask
Used by the Lunar API/status integration.

scylla-driver
Provides the cassandra.* modules used by Lunar's ScyllaDB
database layer.

akinator
Required by the Akinator command.

python-dotenv
Loads the project's .env file automatically.

Pillow
Required for image generation and level-card rendering.

fastapi
Dashboard/backend API framework.

pydantic
Request and data models used by the dashboard.

aioredis
Optional Redis support used by the dashboard.

SQLAlchemy
Optional SQL database support used by the dashboard.

uvicorn
ASGI server used to run the FastAPI dashboard.

---

6. ENVIRONMENT FILE

---

Create:

.env

The bot currently expects:

TOKEN

Example:

TOKEN=your_discord_bot_token

Lunar integrations currently use:

lunar_token
bypass_token

Example:

lunar_token=your_lunar_api_token
bypass_token=your_lunar_bypass_token

T-Music may use:

SPOTIFY_CLIENT_ID
SPOTIFY_CLIENT_SECRET
YOUTUBE_API_KEY
SOUNDCLOUD_CLIENT_ID
TMUSIC_POLL_INTERVAL_MINUTES

---

7. IMPORTANT TOKEN NAME

---

The current bot.py uses:

TOKEN

Do NOT use:

DISCORD_TOKEN

unless bot.py is changed to read that variable.

---

8. DISCORD BOT SETUP

---

Create a Discord application and bot.

Enable the required privileged intents in the
Discord Developer Portal:

Server Members Intent
Message Content Intent

Then place the bot token in:

.env

---

9. SCYLLADB

---

The bot requires a ScyllaDB/Cassandra-compatible database.

The Python package:

scylla-driver

is only the Python driver.

It does NOT install the database server itself.

The current database configuration expects a local database by default.

Typical:

Host: 127.0.0.1
Port: 9042

---

10. DASHBOARD

---

The dashboard backend is located at:

dashboard/backend/main.py

To run it with Uvicorn:

uvicorn dashboard.backend.main:app --host 0.0.0.0 --port 8000

Redis is optional in the current dashboard implementation.

SQLAlchemy database support is also optional.
