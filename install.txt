LUNAR BOT — INSTALLATION GUIDE

This installation guide matches the current Lunar source tree.

---

1. PYTHON VERSION

---

Required:

Python 3.10+

Recommended:

Python 3.11 or newer

---

2. REQUIRED PYTHON PACKAGES

---

Install:

discord.py
aiohttp
akinator.py
python-dotenv
Pillow
psycopg[binary]
psycopg-pool

Dashboard dependencies (optional — only if you run dashboard/backend):

fastapi
pydantic
uvicorn

Also optional, and gracefully skipped if not installed — the
dashboard backend degrades cleanly without them (no Redis
pub/sub, no SQL persistence, but it still runs):

aioredis
SQLAlchemy

Standalone Telegram bots (optional — only if you run telegram/bots/*.py):

python-telegram-bot
httpx

---

3. ONE-COMMAND INSTALL

---

Main bot only:

python -m pip install -U discord.py aiohttp akinator.py python-dotenv Pillow "psycopg[binary]" psycopg-pool

Main bot + dashboard:

python -m pip install -U discord.py aiohttp akinator.py python-dotenv Pillow "psycopg[binary]" psycopg-pool fastapi pydantic uvicorn

5. WHAT EACH PACKAGE IS FOR

---

discord.py
Discord bot framework, commands, slash commands, views,
buttons, modals, events, cogs and tasks.

aiohttp
Asynchronous HTTP requests. Also the transport used internally
by cogs/utilities/lunarapi.py, the shared client every cog uses
to talk to the Lunar API (XP, coins, gacha, profile lookups,
status pings).

akinator.py
Required by the /aki command. Note the PyPI package name is
"akinator.py" even though the code just does "import akinator".

python-dotenv
Loads the project's .env file automatically.

Pillow
Required for image generation and level-card rendering
(cogs/utilities/level_card.py).

psycopg[binary]
PostgreSQL driver. Lunar's database layer (cogs/utilities/database.py)
is PostgreSQL, not ScyllaDB/Cassandra — install this with the
[binary] extra so you don't need local PostgreSQL build tools.

psycopg-pool
Async connection pooling for psycopg (AsyncConnectionPool),
used by the same database layer.

fastapi / pydantic / uvicorn
Only needed if you run the dashboard backend
(dashboard/backend/main.py). Skip these if you're only running
the Discord bot.

aioredis
Optional Redis pub/sub support for the dashboard backend — it's
imported inside a try/except, so the dashboard runs fine without
it (just without Redis-backed features).

SQLAlchemy
Optional synchronous SQL persistence for the dashboard backend —
also try/except-imported, also optional. Note this is a
completely separate DB connection from the bot's own psycopg
layer, even though both currently read the same DATABASE_URL by
default.

python-telegram-bot / httpx
Only needed for the standalone Telegram bots under telegram/bots/
(lunar.py, nova.py, sapphire.py). These are separate processes
from the Discord bot and are not loaded by bot.py.

6. ENVIRONMENT FILE

---

Copy .env.example to .env and fill it in:

cp .env.example .env

The bot currently expects:

TOKEN

Example:

TOKEN=your_discord_bot_token

Lunar API integration (XP, coins, gacha, profile lookups — all
routed through cogs/utilities/lunarapi.py) uses:

lunar_token
bypass_token

Example:

lunar_token=your_lunar_api_token
bypass_token=your_lunar_bypass_token

IMPORTANT — canonical casing: every file that talks to the Lunar
API reads these two names in lowercase. Older versions of
.env.example also listed uppercase "LUNAR_TOKEN"/"LUNAR_BYPASS_TOKEN"
aliases — nothing in the codebase reads those anymore (that was
actually a live bug: cogs/commands/linkaccount.py used to read
the uppercase names while everything else read lowercase, which
meant account-linking's API calls silently ran with no auth token
if only the lowercase vars were set). Only set the lowercase
lunar_token / bypass_token now.

PostgreSQL connection (see section 9):

DATABASE_URL
  -- or individually --
PGHOST
PGPORT (default 5432)
PGUSER / POSTGRES_USER
PGPASSWORD / POSTGRES_PASSWORD
PGDATABASE / POSTGRES_DB (default "lunar")

T-Music may use:

SPOTIFY_CLIENT_ID
SPOTIFY_CLIENT_SECRET
YOUTUBE_API_KEY
SOUNDCLOUD_CLIENT_ID
TMUSIC_POLL_INTERVAL_MINUTES

9. DATABASE — POSTGRESQL

---

Lunar's database layer (cogs/utilities/database.py) runs on
PostgreSQL via psycopg + psycopg_pool. It is NOT ScyllaDB or
Cassandra, despite older docs/wiring in this project claiming
otherwise — the "scylla-driver" package that used to be listed
here does not exist anywhere in the actual import graph.

Point the bot at your PostgreSQL instance with either a single
DSN:

DATABASE_URL=postgresql://user:password@host:5432/lunar

...or individual vars (all optional, sensible defaults shown):

PGHOST=127.0.0.1
PGPORT=5432
PGUSER=your_postgres_user
PGPASSWORD=your_postgres_password
PGDATABASE=lunar

The bot creates its own tables on startup (see the CREATE TABLE
statements in cogs/utilities/database.py) — you just need an
empty database and working credentials.

Make sure PostgreSQL is running and reachable before starting
Lunar.

10. DASHBOARD

---

The dashboard backend is located at:

dashboard/backend/main.py

It's a small FastAPI app — only fastapi, pydantic and uvicorn are
needed to run it, nothing else.

To run it with Uvicorn:

uvicorn dashboard.backend.main:app --host 0.0.0.0 --port 8000

12. START THE BOT

---

From the Lunar project root:

python bot.py

Lunar auto-discovers every .py file under cogs/ (except
cogs/utilities/) at startup and loads each as a cog — new cog
files don't need to be registered anywhere by hand.

13. QUICK SETUP

---

python -m venv .venv

Activate the environment.

Then:

python -m pip install --upgrade pip

Then:

python -m pip install -U discord.py aiohttp akinator.py python-dotenv Pillow "psycopg[binary]" psycopg-pool fastapi pydantic uvicorn

Create:

.env

Set:

TOKEN=your_discord_bot_token
lunar_token=your_lunar_api_token
bypass_token=your_lunar_bypass_token
DATABASE_URL=postgresql://user:password@host:5432/lunar

Configure the other API credentials required by the enabled
features (T-Music/Spotify/YouTube/SoundCloud if you use it).

Make sure PostgreSQL is running and reachable.

Then start Lunar:

python bot.py
